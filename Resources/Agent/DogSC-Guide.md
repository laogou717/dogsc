# DogSC 使用说明（给 AI 回答"怎么做"用）

回答时用用户界面上的名字，按"在哪 → 点什么"给出路径。能直接用工具改的，先问一句或直接改，不要只讲步骤。

## 界面结构
- 编辑器分三栏：左栏（素材 / 字幕 / AI 三页）、中间画布、右栏（检查器）。下方是时间线。
- 右栏首页是"全片设置"：背景、布局、样机、光标、摄像头、声音、开场、运镜。点一行进入，⌘[ 或两指右划返回。
- 选中时间线或画布上的对象，右栏直接显示该对象的设置。
- ⌥⌘L 显示/隐藏左栏，⌥⌘I 显示/隐藏右栏，⌘/ 打开快捷键速查。

## 录制
- 菜单栏或录制条开始录制；录制条可选：区域 / 窗口 / 屏幕、麦克风、摄像头、系统声音。
- 录完右下角出现结果卡：保存项目（Esc 同效）、进入编辑（回车）、标题旁废纸篓删除（5 秒内可撤销）。
- 录制时鼠标点击会被记下，用来自动生成缩放。

## 剪辑（主轨道）
- S：在播放头分割；Q / W：波纹删除播放头前 / 后的部分；D 或 Delete：删除选中。
- ⌥ 点击主片段：在点击处切开。悬停两个片段之间的剪切缝：合并或还原该处剪切。
- 右键点按主片段，选择「片段速度」即可调整倍速（1×–100×）。素材可从左栏拖进主轨道插入，后面的内容整体后移。
- 时间线左上的"剪切点"按钮：显示剪切点，便于查看和合并剪切。

## 缩放与 3D（运镜）
- 缩放轨：在空白处拖动创建缩放，单击创建 3 秒；选中后在右栏改放大倍数、焦点、速度。
- 要放大已导入的录屏，选中绿色缩放片段，在右栏「缩放对象」选「叠加视频」，再在素材缩略图上点选焦点。缩放随当前最上层的视频跨过切点，摄像头和字幕保持各自的位置。
- 自动缩放：录制时的点击会生成标"自动"的缩放片段，可删除或修改。
- 屏幕 3D：在运动轨空白处拖动创建；右栏调整旋转、缩放、透视。
- 默认缩放倍数与过渡时长：全片设置 → 运镜。
- ⌘C / ⌘V 复制粘贴效果片段；⌘⇧V 把属性粘贴到选中的同类片段。

## 标记与遮挡
- 时间线"柔化"轨：添加柔化（遮住隐私）或聚光（压暗四周、突出一块区域）。在画布上直接拖动调整范围。

## 字幕
- 左栏"字幕"页编辑全部字幕；时间线字幕轨空白处单击添加一条。
- 字幕样式（字号、底部距离、背景）在选中字幕后的右栏。
- AI 可以用本机语音识别生成字幕、按语音对齐时间。

## 画面样式（全片设置）
- 背景：四个页签——壁纸、网格（图案，可调图案大小）、动效（动态壁纸）、自定（选择自己的图片或视频）。
- 布局：边距、圆角、阴影强度、描边；标题栏的"场景预设"可一键套用整套样式，也能保存自己的布局预设。
- 样机：无边框 / macOS 窗口 / 浏览器 / iPhone / iPad。
- 光标：光标样式、大小、静止后隐藏、点击反馈与点击颜色；也可隐藏光标。
- 摄像头：形状、大小、位置、描边、镜像摄像头；也可在画布上直接拖动。
- 声音：系统声音与麦克风各自的音量和静音。
- 开场：内置开场动画（全局开场）。
- 画面比例：画布下方"16:9"菜单；裁切：画布下方"裁切"。

## 叠加内容
- 画布下方"添加"或左栏素材拖到画布：图片、视频、动效、音乐、音效。
- 在时间线上右键点按叠加视频，选择「片段速度」调整倍速。放快会缩短时间线上的片段，选取的源画面和随片段播放的声音一起变速。
- 选中叠加视频，在右栏「蒙版」选择矩形、圆角矩形或圆形。选圆角矩形后可调「圆角程度」（占视频短边的 0% 到 50%）。
- 有摄像头的片段可在「叠放顺序」选择「摄像头在上」或「视频在上」。新导入默认摄像头在上，之后沿用上一次手动选择。
- HTML 动效：选中后在右栏改文字、颜色；直接点画面里的文字可拖动、Delete 隐藏、方向键微调。

## 导出
- ⌘E 导出成片；⌥X 导出选中的主片段范围。分辨率、帧率、编码在导出面板里选。
- 默认导出位置：设置（⌘,）→ 编辑与导出 → 导出到。

## 设置窗口（⌘,）
- 通用：语言、外观、项目保存位置、素材库位置。
- 编辑与导出：默认预览画质、导出位置、导出完成提示音、恢复编辑窗口布局。
- 录制：默认录制系统声音、默认麦克风、摄像头悬浮窗。
- 权限：屏幕录制、辅助功能（必需）；摄像头、麦克风（可选）。红点表示缺权限。

## 撤销
- 每次 AI 修改是一步，可在对话里"撤销全部"，或 ⌘Z 逐步撤销。
